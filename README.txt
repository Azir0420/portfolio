蛇形學習作品集｜第三階段：蘋果互動與獨立作品頁

檔案結構：
- index.html：首頁與蛇形學習時間軸
- css/style.css：首頁外觀、響應式版面、蛇身動畫與蘋果連結互動
- css/project-detail.css：8 個作品介紹頁共用樣式
- js/main.js：依照頁面捲動進度更新蛇頭、蛇身節點與蘋果狀態
- projects/project-01.html ～ project-08.html：8 個獨立作品介紹頁
- images/project-01.png ～ project-08.png：使用者提供的 8 張實際作品截圖

如何預覽：
1. 使用 VS Code 開啟 snake-learning-portfolio-phase3 資料夾。
2. 使用 Live Server 開啟 index.html。
3. 點擊時間軸上的蘋果，或作品卡片中的「查看作品」。
4. 進入對應的獨立作品介紹頁。
5. 點擊「返回作品時間軸」回到首頁。

第三階段完成項目：
- 8 顆蘋果都可以點擊。
- 8 個作品卡片中的「查看作品」都可以點擊。
- 每個作品都有自己的 HTML 網址。
- 內頁包含作品介紹、學習重點、使用技術、實際作品截圖及原始檔案連結。
- 內頁可以返回首頁時間軸。
- 蘋果連結支援鍵盤操作。

重要提醒：
- 作品資料依照目前提供的原始內容整理；第二個作品日期仍標示待確認，沒有自行補日期。
- 原始練習檔案未包含在 ZIP 中。若要讓「開啟原始練習」按鈕正常運作，請將對應 HTML 檔案放在專案根目錄（與 index.html 同一層）。
- 8 張作品截圖已依照使用者確認的順序放入 images 資料夾。點擊內頁截圖可在新分頁查看完整尺寸。
- 第 7 個作品為 Ch.8 Forms 表單練習；第 8 個作品為企業教育訓練線上報名表單。
- Google Fonts 需要網路連線；若無法連線，會使用系統字型。


修正版：最後一顆蘋果無法抵達（大視窗）
- 蛇的路線會依照每顆蘋果實際中心點建立。
- 蛇頭進度以第一顆與最後一顆蘋果的位置計算。
- 最底部會將進度補足至 100%，不再因大視窗高度而停在終點前。
- 蛇頭及蛇身改為獨立上層 SVG，抵達蘋果時不會被節點遮住。


作品頁面調整：各作品頁底部不再顯示原始 HTML 檔案名稱；「開啟原始練習」連結仍保留。若要使用該連結，請將對應原始 HTML 檔案放在專案根目錄。
